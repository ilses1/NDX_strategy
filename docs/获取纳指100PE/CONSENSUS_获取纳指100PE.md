# CONSENSUS_获取纳指100PE

## 1. 明确的需求描述和验收标准
- **需求**: 每日运行脚本，抓取纳指100的 PE 和当前点位，根据 `bs.md` 中的策略逻辑，计算并输出当天的投资操作建议。
- **验收标准**:
    - 脚本能稳定获取纳指100 PE 数据。
    - 策略逻辑完全覆盖 `bs.md` 中的四个维度：基础定投、回撤加码、赎回止盈、买回。
    - 输出结果清晰，包含：当前数据（PE, 点位, 回撤）、操作建议（买入金额/赎回比例）、触发理由。
    - 自动维护历史高点和历史数据文件（CSV）。

## 2. 技术实现方案和约束
- **技术栈**: Python 3.x
- **核心库**: `requests` (API抓取), `pandas` (数据处理/持久化), `python-dotenv` (配置管理)。
- **数据源**: 
    - 蛋卷基金 API: `https://danjuanfunds.com/djapi/index_valuation/results` 获取 PE 和百分位。
    - 由于回撤需要指数点位，将从 API 响应中提取 `value` (指数值) 或使用 `current` 字段。
- **数据存储**: 使用 `data/history.csv` 存储每日抓取到的记录，包括日期、PE、指数值、回撤百分比、建议操作。
- **回撤计算**: 维护一个 `data/config.json` 记录“近期高点”点位。每次运行脚本时，如果当前点位 > 记录高点，则更新高点；否则计算回撤。

## 3. 任务边界限制
- **不涉及**: 自动下单交易（仅做提示）。
- **不涉及**: 复杂的图形化界面（仅命令行输出和日志）。
- **不涉及**: 实时监控（每日触发一次即可）。

## 4. 确认的决策
- **回撤高点**: 初始设为脚本第一次运行时的点位，或通过爬虫获取过去一年的最高点作为初始值。
- **通知方式**: 默认控制台打印，并记录在 `logs/recommendations.log` 中。
- **自动化**: 建议用户配合 Windows 任务计划程序或 GitHub Actions 使用。
