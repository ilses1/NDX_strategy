# ALIGNMENT\_获取纳指100PE

## 1. 项目和任务特性规范

- **项目名称**: pyFund
- **任务名称**: 每天获取纳指100 PE
- **技术栈**: Python (基于项目目录名推断)
- **目标网站**: https://danjuanfunds.com/rn/value-center

## 2. 需求理解确认

### 原始需求

每天访问 `https://danjuanfunds.com/rn/value-center` 获取纳指100 PE。

### 边界确认 (明确任务范围)

- **输入**:
  - 蛋卷基金指数估值页面 URL (`https://danjuanfunds.com/rn/value-center`)。
  - 定投规则文档 (`bs.md`)。
- **处理**:
  - 自动化访问网页获取最新的纳指100 PE 和价格数据。
  - 维护历史最高点数据以计算回撤。
  - 根据 `bs.md` 的金字塔定投策略（激进版）计算每日定投金额或赎回建议。
- **输出**: 每日投资提示（定投金额、赎回比例、或买回建议）。
- **频率**: 每天一次。

### 需求理解 (对现有项目的理解)

- 当前项目需要实现一个基于策略的自动化提醒工具。
- 策略包含：基础定投（基于PE）、回撤加码（基于回撤，优先级最高）、赎回止盈（基于PE）、买回规则（基于PE）。

### 疑问澄清 (存在歧义的地方)

1. **回撤高点定义**: “近期高点”的具体时间范围是多少？（例如：过去250个交易日，还是从本轮牛市开始？通常指历史最高点或滚动年度最高点。建议使用滚动250日最高点或项目启动以来的最高点）。
2. **数据源**: 蛋卷 API 提供 PE，但回撤通常需要价格数据。是否同时从蛋卷获取价格，或从第三方（如雅虎财经）获取 `NDX` 指数价格？
3. **通知方式**: 每天如何“提示”？（控制台输出、写入本地文件、发送邮件、或者微信推送？建议初始实现控制台输出和本地文件记录，并预留推送接口）。

## 3. 智能决策策略 (初步)

- **优先策略**: 尝试查找蛋卷基金的公开/内部 API，以减少对重量级浏览器自动化的依赖。
- **存储建议**: 初始阶段建议使用 CSV 文件记录，方便查看历史趋势且无需复杂数据库配置。
- **运行建议**: 建议编写一个独立的 Python 脚本，支持通过命令行参数运行，并提供一个 GitHub Action 配置示例以实现自动化。

## 4. 关键决策点询问 (按优先级排序)

1. **Q1**: 您希望如何存储这些历史数据？(推荐: CSV 文件)
2. **Q2**: 您打算在哪里运行这个程序？(推荐: 本地运行或 GitHub Actions 自动运行)
3. **Q3**: 除了 PE 之外，还需要获取其他数据吗？(如 PB、百分位、股息率等)
4. **Q4**: 如果网站反爬虫或 API 变更，是否需要报警通知？
