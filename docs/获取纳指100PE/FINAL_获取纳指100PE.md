# FINAL\_获取纳指100PE

## 1. 项目总结报告

本项目实现了一个基于 Python 的纳指100金字塔定投策略提示工具。该工具每日抓取纳指100最新的估值 (PE) 和点位 (Value)，并根据 `bs.md` 中定义的激进版定投规则生成操作建议。

### 核心功能

1. **多源数据抓取**: 优先从雪球 (Xueqiu) 获取实时指数点位，尝试从蛋卷 (Danjuan) 获取 PE，并具备历史数据回退机制，确保在 API 受限时仍能提供基于最新已知数据的判断。
2. **自动化策略计算**:
   - **回撤加码**: 自动追踪历史最高点，计算当前回撤。回撤 >= 6% 时触发，优先级高于 PE 规则。
   - **基础定投**: PE 在 32-38 之间按档位定投。
   - **分批止盈**: PE >= 40/42/45 分批赎回。
   - **一键买回**: PE 回落至 35 以下时，提示买回所有已赎回资金。
3. **状态持久化**:
   - `data/state.json`: 存储历史最高点和策略执行状态（如是否已买回）。
   - `data/nasdaq_history.csv`: 记录每日历史轨迹。
   - `logs/strategy.log`: 详细的操作理由日志。

## 2. 交付物清单

- `nasdaq_strategy.py`: 核心执行脚本。
- `requirements.txt`: 依赖项。
- `data/`: 数据存储目录。
- `logs/`: 日志存储目录。
- `docs/`: 任务执行全流程文档。

## 3. 使用说明

1. 安装依赖: `pip install -r requirements.txt`
2. 运行脚本: `python nasdaq_strategy.py`
3. 建议配合 Windows 任务计划程序或 Linux Crontab 设置每日定时运行。
